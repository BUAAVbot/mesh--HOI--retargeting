## 运行方式

只读复用服务器已有 `/data/grail-envs/tracking45`：Isaac Sim 4.5、Isaac Lab 2.1、Python 3.10 和 Torch 2.5.1。训练使用物理 GPU 7，评估使用物理 GPU 6，PhysX 逻辑 `cuda:0`，不修改共享源码或安装包，不运行收费服务。

```bash
cd /data/KinoGen
# 每次选择尚不存在的新输出目录。
bash scripts/run_g1_box.sh --mode preflight --num-envs 4 \
  --run-dir outputs/g1_box_training/NEW_PREFLIGHT
bash scripts/run_g1_box.sh --mode train --num-envs 256 --iterations 300 \
  --run-dir outputs/g1_box_training/NEW_TRAIN
KINOGEN_CUDA_DEVICES=6 bash scripts/run_g1_box.sh --mode eval --num-envs 32 \
  --asset-config data/robots/g1_box_training/reset_v2.json \
  --stage-box-before-reset --seed 210001 \
  --checkpoint outputs/g1_box_training/NEW_TRAIN/final.pt \
  --run-dir outputs/g1_box_training/NEW_EVALUATION
```

这些是可运行入口，不代表上述训练次数必然收敛。真实执行进度以该次 `metrics.jsonl`、`training_receipt.json` 和独立验收为准。

## 策略、模型和初始任务

机器人是浮动 G1 身体与左右五指 ROHand：29 个身体控制量和12个手部输入，共41个策略输出。厂家非线性连杆函数通过1025点 LUT 展开为50个手关节位置目标，共79个物理运动关节、89个刚体链接。该实现使用50个位置伺服驱动近似机械连杆，接触时实际状态不一定严格满足目标耦合；不等于真实六电机闭链动力学。

派生模型位于 `data/robots/g1_box_training/`，不改原始 CAD、冻结重建轨迹或厂家模型。源惯量为正定；为数值条件改善，明确记录了小质量/惯量正则化、固定传感器坐标质量假设和模拟手部力矩/速度。外碰撞使用57个凸包，28个内部滑块/连杆保留动力学而不参与外接触。自碰撞目前关闭。真实的 PD 增益、惯量、力矩与速度配置随每次仿真报告保存，不把实验参数冒充硬件标定。

任务初始为双脚站地、双手张开且与箱子分离；箱子为1 kg、受重力的动态刚体，支撑于0.81 m桌面。桌面占地 X 为[0.15,0.51] m，与机身保持间隙。训练使用明确声明的闭手/抬升 IK 参考和 PPO 反馈残差，观测包含本体及物体状态；不是视觉搜索或纯语言控制。实际运动只由电机目标和物理接触产生，不在活动回合内写机器人/箱体位姿、关节状态或注入外力，也不焊接箱子。

## 训练与成功验收分开

真实训练证据包括优化器更新次数、环境转移数、训练前后 actor 权重哈希和有限性；评估必须加载对应检查点并记录真实策略前向次数。无训练的零残差参考预检仅作对照，不称为训练成功。

最终评估预定32个独立随机种子，每个回合从桌面、张手、不预抓开始，保存首次真实终止前的状态。成功需要同时满足：

- 箱子旋转后的最低点比桌面高至少0.10 m，不能只用质心高度掩盖倾斜。
- 左右手与箱子的真实过滤接触力各大于0.5 N，箱子与桌面接触力小于0.2 N。
- 末端连续维持至少2 s，机器人保持直立、未跌倒且脚部有支撑。
- 活动期间无位姿/关节状态强制写入、无外力托举、无附着约束。

`scripts/audit_g1_box_policy.py` 在 CPU 独立读取 `trace.npz`、`live_physics.json`、检查点和视频来源；缺失证据判为未验证。训练反馈可使用 `--trace-only`，该模式永远不会判定最终交付完成。32次评估的失败回合不会删除。

## 视频来源和结果边界

录像使用实际捕获的刚体位置与四元数离线渲染，避免已知 Isaac 4.5 摄像头开启对物理预检的干扰。MuJoCo仅显示记录状态，不重新计算动力学，不用参考动作替换结果。视频来源 JSON 绑定检查点 SHA、完整轨迹 SHA、每个视频帧的真实采样索引和编码文件 SHA。
